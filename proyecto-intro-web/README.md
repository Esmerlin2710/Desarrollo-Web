# Proyecto: Mi página personal

Proyecto de Introducción al Desarrollo Web realizado únicamente con HTML5 y CSS3.

## Estructura
- `index.html`: contenido y estructura semántica.
- `css/styles.css`: estilos externos.
- `assets/img/programacion.svg`: ilustración local.

## Cómo abrir
Descarga o descomprime el proyecto y abre `index.html` en un navegador.

## Requisitos incluidos
- Encabezado y menú con enlaces internos.
- Sobre mí con imagen y etiquetas `strong` y `b`.
- Intereses en una lista sin ordenar.
- Tabla de actividades.
- Formulario con nombre, correo, mensaje y botón.
- Pie de página.
- Más de 20 elementos HTML diferentes y CSS separado.

**Nota:** El formulario es demostrativo. No almacena ni entrega mensajes porque el proyecto no utiliza servidor ni JavaScript.
